# 💿 Ressources de l'installateur — ArcIA

> **[🏠 Accueil ArcIA](../../README.md)** › **[🎨 Assets](../README.md)** › **Installateur (`assets/installer/`)**

Ce dossier contient les ressources graphiques et le script de compilation pour les installateurs de bureau **ArcIA** (Inno Setup / lanceurs Windows).

---

## 📦 Fichiers disponibles

| Fichier | Format | Description |
|---|---|---|
| **[app.ico](app.ico)** | ICO Multi-résolutions | Icône Windows officielle (de `16x16` à `256x256` px). |
| **[wizard-header.bmp](wizard-header.bmp)** | Bitmap | Bandeau supérieur de l'assistant d'installation natif. |
| **[wizard-side.bmp](wizard-side.bmp)** | Bitmap | Illustration latérale d'accueil et de fin d'installation. |
| **[installer-sample.iss](installer-sample.iss)** | Script Inno Setup | Modèle de compilation permettant de générer un installeur `.exe` autonome. |
