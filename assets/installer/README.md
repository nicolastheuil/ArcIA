# Ressources de l'Installateur — ArcIA

Ce dossier contient les assets graphiques et le script de packaging pour les installateurs de bureau ArcIA (Inno Setup / exécutables d'installation).

## Fichiers Disponibles

* `app.ico` : Icône multi-résolutions Windows (16x16 à 256x256).
* `wizard-header.bmp` : Image d'en-tête du bandeau supérieur de l'assistant d'installation.
* `wizard-side.bmp` : Image latérale du panneau d'accueil et de fin d'installation.
* `installer-sample.iss` : Script modèle de compilation Inno Setup permettant de produire un binaire d'installation autonome.
