Active oauth2-proxy et le middleware Traefik ForwardAuth pour verrouiller l'accès aux collaborateurs.

Comment créer l'application dans Microsoft Entra ID ? (Guide pas-à-pas) ▼
  1. Portail Azure > Microsoft Entra ID > Inscriptions d'applications > + Nouvelle inscription.
  2. Nom : ArcIA-SSO | Types de comptes : Mono-locataire.
  3. URI de redirection (Web) : https://<fqdn>/oauth2/callback.
  4. Copiez ID d'application (client) et ID de l'annuaire (tenant).
  5. Dans Certificats & secrets, créez un secret et copiez sa Valeur.

Guide détaillé SSO Entra ID sur GitHub ↗

Étape 7 : Adaptateur Microsoft Teams Bot

Optionnel : Intégrez le bot ArcIA dans Microsoft Teams (chats 1:1 et mentions @ArcIA en canaux).

Activer le Bot Microsoft Teams

Déploie le microservice adaptateur Teams Bot et route les webhooks Azure Bot Service.

Comment créer le bot sur Azure Bot Service ? (Guide pas-à-pas) ▼
  1. Portail Azure > Créer une ressource Azure Bot.
  2. Dans Configuration, renseignez l'URL de messagerie : https://<fqdn>/api/teams/messages.
  3. Copiez le Microsoft App ID et générez le secret dans Gérer le mot de passe.
  4. Dans Canaux, activez le canal Microsoft Teams.
